# db-v1 2026-10-15 검수 반영

현재 게시된 db-v1 두 ZIP을 SHA256으로 고정해 사용한다. 로컬 Pi DB나 어제 실패한 배치 파일은 **입력으로 사용하지 않는다**.

## 자동 반영 내용

1. 전체 236개 원본키의 검수 판정을 SQLite 테이블 multiwork_review_decisions_20261015 에 저장한다. 검수행과 릴리즈원본번호는 별도 유지.
2. 확정된 5개 출처 링크만 entries.cross_source_ids_json에서 직접 교정한다. Onnada:384 (1980년 철인), Onnada:6169 (재생되는 THE LAST ATTACK), ReAnime:hamelin-no-violin-hiki-jxynbq (극장판), Anissia:2695 (히프노시스 마이크+), Anissia:3160 (천수 특별편).
3. 보류·공개대기·판본분리·회차구간·제목 결정은 검수 원장으로 보존한다. **기존 자동회차, 자막배정, 수동 작업을 새로 생성하거나 바꾸지 않는다.** 펭귄드럼 전·후편과 슬라임 총집편, 체포하겠어 TV 51화도 원장에 기록한다.
4. 종전 2026-10-11 검수 원장, 자막 레지스트리(확정 12,055회차), Anikoto 검수 링크를 보존한다. 허용되지 않은 기존 테이블 변경 발견 시 중단한다.
5. Pi의 PostgreSQL 운영 DB는 직접 건드리지 않는다. 업데이트된 릴리즈를 Pi에 적용하는 작업은 별도다.

## 배포 안전 조건

- 현재 릴리즈 두 ZIP SHA-256, 전체 CSV 236건, 세부 결정 54건, 5개 수정 원본 ID 및 검수 원장을 검사한다.
- pull_request에서는 검증만, main push에서만 재검증 후 기존 db-v1을 갱신한다.
- 업로드 전 원본 카탈로그를 anime_four_sources_multilingual_prepared.before-multiwork-20261015.zip 이름으로 백업하고, 게시 ZIP을 재다운로드해 SHA-256 비교한다. 실패 시 원본을 복원한다.
- 나머지 236건의 분리 표시, 한글 이름, 영상별 회차 매핑이 앱에 적용되려면 런타임 로직이나 관련 DB 테이블의 추가 교정이 필요하다. **검수 원장 기록을 즉시 영상 연결 완료라고 주장하지 않는다.**
